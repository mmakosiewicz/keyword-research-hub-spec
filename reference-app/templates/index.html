Why a core is required

The generator measures every candidate's semantic distance from the keywords that define your site. Mark representative, on-topic terms as core before generating.

  1. 1. Embed — semantic vectors.
  2. 2. Cluster — group and name core topics.
  3. 3. Tier — distance to nearest core cluster.
  4. 4. Score BP — optional product fit 0–3.
